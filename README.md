# Лабораторная работа 1: матрицы комплексных чисел

Программа умеет складывать, умножать и делить матрицы A и B, транспонировать их и считать определитель.

## Файлы

- `Main.java` — меню и ввод, **запускать его**
- `ComplexMatrix.java` — матрица и операции с ней
- `Complex.java` — комплексное число

## Запуск

```
javac -encoding UTF-8 *.java
java Main
```

## Ввод

Пункт меню выбирается цифрой. Элемент матрицы вводится одним или двумя числами через пробел: `3` — это 3, `3 -2` — это 3−2i, как пример.
