# Лабораторная работа 1: матрицы комплексных чисел

Консольная программа на Java для работы с матрицами, элементы которых — комплексные числа.

## Возможности

- ввод матриц A и B произвольного размера;
- сложение A + B;
- умножение A * B;
- деление A / B (как A * B⁻¹);
- транспонирование A и B;
- определитель A и B.

## Файлы

- `Main.java` — меню и ввод, **запускать его**
- `ComplexMatrix.java` — матрица и операции с ней
- `Complex.java` — комплексное число

## Запуск

Нужен JDK 8 или новее.

```
javac -encoding UTF-8 *.java
java Main
```

## Ввод данных

1. Выбрать пункт меню цифрой и нажать Enter.
2. Для ввода матрицы указать число строк и столбцов.
3. Каждый элемент вводится одним или двумя числами через пробел — действительная и мнимая часть:
   - `3` → 3 + 0i
   - `3 -2` → 3 − 2i
   - `1.5 0.5` → 1.5 + 0.5i
4. М-цы записываются, далее можно выбирать пункты 3-9

## Ограничения

- Сложение — только для матриц одного размера.
- Умножение — число столбцов A должно равняться числу строк B.
- Деление и определитель — только для квадратных матриц; для деления определитель B не должен быть равен нулю.
- Определитель считается разложением по первой строке, поэтому для матриц больше 10×10 вычисление заметно замедляется.
- Результаты выводятся с округлением до двух знаков после точки.
